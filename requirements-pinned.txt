# nuarr - the working set, pinned.
#
# Taken by `pip freeze` on the box nuarr runs on, on the day every engine was
# measured working: PaddleOCR on the GPU at 0.17 s/cue, faster-whisper on CUDA
# at 1 cpu-second a file. If an upgrade breaks one of them, this is the way
# back:
#
#     python -m pip install -r requirements-pinned.txt
#
# THE PART THAT MATTERS is the first block. paddlepaddle-gpu and ctranslate2
# (under faster-whisper) both load CUDA and cuDNN from the nvidia-* wheels
# below, and they must agree on the versions - that is the whole reason this
# file exists.
#
# ONE THING THIS FILE CANNOT PIN: import order. paddle and ctranslate2 loaded
# into the SAME process, paddle first, fails with
#     OSError: [WinError 127] The specified procedure could not be found
# because each brings its own view of the CUDA DLLs. nuarr never does this -
# paddle_worker.py runs PaddleOCR in its own process for exactly this reason,
# and faster-whisper lives in the server. Keep it that way.
#
# RapidOCR is deliberately absent. It was measured (0.66 s/cue on the CPU
# against Paddle's 0.17 on the card) and taken back out.
