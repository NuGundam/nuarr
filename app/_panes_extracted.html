          A second OCR engine, and the more accurate one. Tesseract is bundled

          The working folder. Every encode is written here in full before it
          replaces the original, so it wants to be fast, local and roomy
          — and it must not be on the pool. Writing output to the
          same spindles being read from turns one sequential read into a read
          and a write on the same disk, which is the easiest way to make Plex
          stutter while nuarr works. Nothing is moved when you change this:
          anything mid-flight finishes against the old folder, and the next job
          starts using the new one.

          A language tag is the one thing about a file nuarr cannot take on
          trust and cannot work out from anything else. An empty tag is not
          neutral — Sonarr, Radarr and every player read a blank as
          English — and a wrong tag looks exactly like a right one.
          So it is measured: three 30-second windows from the middle of
          the file, through Whisper’s language identifier, and the
          confident windows have to agree. This page shows what was heard,
          what the files claim, and — deliberately — every case
          where nuarr refused to answer.
