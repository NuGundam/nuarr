            Does the audio picker tell the truth?
            

              A track's title is written by whoever made the release, and it
              describes the source. Once nuarr converts the stream the title
              outlives the thing it described — so Plex offers you
              TrueHD 5.1 for a track that is now
              E-AC3, or English FLAC 5.1 for one that
              is stereo AAC with no centre channel at all. Only titles that
              actually contradict the stream are listed; a vague one is not a
              wrong one, and anything carrying a word beyond format — a
              commentary, a fansub group — is left alone.

          What happens to each audio track that survives the language policy,
          per library. Which tracks are KEPT is decided on the
          Languages page; this decides what they are converted to.
          The goal throughout is a track Plex hands to the client untouched:
          a format it direct-plays, at a bitrate its decoder accepts, with a
          channel count the client already has speakers for. Anything else and
          Plex remixes or re-encodes on the fly, which is the cost this whole
          system exists to avoid.

    Which nuarr this is, and whether there is a newer one. Checking is
    automatic once a repository is set; installing never is. nuarr is
    usually part-way through an encode or a commit, and swapping its own files
    under a running ffmpeg would leave a half-written file in the library
    — the one outcome the whole system exists to prevent. So this page
    tells you, and you choose when.
  

  





        

          The working folder. Every encode is written here in full before it
          replaces the original, so it wants to be fast, local and roomy
          — and it must not be on the pool. Writing output to the
          same spindles being read from turns one sequential read into a read
          and a write on the same disk, which is the easiest way to make Plex
          stutter while nuarr works. Nothing is moved when you change this:
          anything mid-flight finishes against the old folder, and the next job
          starts using the new one.

          A language tag is the one thing about a file nuarr cannot take on
          trust and cannot work out from anything else. An empty tag is not
          neutral — Sonarr, Radarr and every player read a blank as
          English — and a wrong tag looks exactly like a right one.
          So it is measured: three 30-second windows from the middle of
          the file, through Whisper’s language identifier, and the
          confident windows have to agree. This page shows what was heard,
          what the files claim, and — deliberately — every case
          where nuarr refused to answer.
